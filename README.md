# GoWaggle for Windows

Downloads for the GoWaggle desktop app. Talk to whoever's around, in a window of its own.

**Get it from [gowaggle.pages.dev/download](https://gowaggle.pages.dev/download)**, or grab `GoWaggle-Setup.exe` from the [latest release](https://github.com/RealRanger/gowaggle-desktop/releases/latest).

- Works on Windows 10 and 11.
- Installs by itself, and keeps itself up to date.
- If Windows says it protected your PC, choose **More info**, then **Run anyway**.

This repository only holds the installers. To report a problem, use the report options inside GoWaggle.
